# SkillForge: The Software Engineering Blueprint - Landing Page

Welcome to **SkillForge**'s landing page for the e-book *The Software Engineering Blueprint*. This repository contains the code and design for the landing page, which provides an overview of the e-book that guides aspiring software engineers through key concepts, best practices, and career pathways.

## Project Overview

*The Software Engineering Blueprint* is a comprehensive guide for beginners and intermediate developers who want to dive deeper into the world of software engineering. This landing page introduces the e-book's content, provides key insights, and includes features like call-to-action buttons, author information, testimonials, and more.

The project is built using:
- **ReactJS** with **Vite** for a fast and optimized development environment.
- **TailwindCSS** for utility-first styling, enabling quick and scalable design.
- **Styled Components** for custom, reusable components and more flexibility.

## Features
- **Responsive Design**: Ensures a seamless experience across various devices (desktop, tablet, mobile).
- **Elegant UI**: Clean and modern design, combining TailwindCSS and Styled Components for efficient styling and customization.
- **Interactive Elements**: Includes buttons for downloading the e-book, exploring the table of contents, and engaging with testimonials.
- **SEO Optimized**: Built to be SEO-friendly, helping users discover the e-book easily.

## Tech Stack
- **ReactJS** – JavaScript library for building the user interface.
- **Vite** – A fast build tool for a streamlined development experience.
- **TailwindCSS** – A utility-first CSS framework for fast and efficient styling.
- **Styled Components** – A CSS-in-JS library for writing scoped and reusable component styles.

## Getting Started

### Prerequisites
Ensure that you have **Node.js** installed on your machine. If you don't have it, download and install it from [nodejs.org](https://nodejs.org/).

### Installation
To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/skillforge-blueprint-landing.git
2. Navigate into the project directory:
   ```bash
   cd skillforge-blueprint-landing
3. Install dependencies:
   ```bash
   npm install
4. Start the development server:
   ```bash
   npm run dev
